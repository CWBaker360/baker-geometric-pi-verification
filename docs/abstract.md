# Abstract

This report documents a synchronized, reproducible numerical verification
suite for Baker's algebraically constructed geometric constant \(\pi_g\). The
construction begins with the exact hexagon seed, selects the required cubic
branch using a deterministic sign-changing bracket, forms a scale-3 polygon
sequence, and applies an even-power Richardson table. Classical \(\pi\) is not
consulted during construction or candidate selection.

After \(\pi_g\) is fixed, eight cross-domain checks are performed using direct
residuals, explicit truncation enclosures, or two-sided inequalities. All eight
checks pass at 120-decimal-digit working precision. The results are consistency
evidence and do not substitute for a proof that \(\pi_g=\pi\).
